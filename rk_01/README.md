# Рубежный контроль 1

Вариант предметной области **22: Библиотека — Язык программирования**.
Использован набор запросов **А**, как в исходном комплекте.

```bash
python3 rk_01/main.py
```

Запуск из корня `pcpl-labs`, Python 3.10+, внешних зависимостей нет.

- А1: библиотеки и основные языки, сортировка по языкам.
- А2: языки с суммарным числом модулей библиотек, по убыванию суммы.
- А3: языки с отдельным словом «язык» и их библиотеки по связи M:N.

«Сотрудник», «отдел» и «зарплата» из шаблона условия заменены библиотекой,
языком программирования и числом модулей. Для А3 используется слово «язык».
Число модулей (12, 8, 6, 4) — условные учебные значения.
Основной язык задаёт связь 1:N; Polars связан с Python и Rust через M:N.
Коллекции содержат 4 библиотеки, 3 языка и 5 связей. При равенстве основных
ключей результаты сортируются по названию; А2 исключает пустые группы.
